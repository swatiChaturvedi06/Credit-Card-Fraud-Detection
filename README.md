# 💳 Credit Card Fraud Detection Using AI & Machine Learning

## 📌 Project Overview
This project focuses on detecting fraudulent credit card transactions using Artificial Intelligence and Machine Learning techniques. It analyzes transaction data and classifies transactions as Genuine or Fraudulent.

## 🎯 Project Objective
The main objective is to develop a machine learning model that can identify suspicious credit card transactions and help prevent financial fraud.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Machine Learning

## 📊 Dataset Information

The dataset contains 100,000 transactions.

| Transaction Type | Number of Transactions |
|---|---:|
| Genuine Transactions | 99,000 |
| Fraudulent Transactions | 1,000 |
| Total Transactions | 100,000 |

### Dataset Features
- TransactionID
- TransactionDate
- Amount
- MerchantID
- TransactionType
- Location
- IsFraud
